Changelog

What changed, and what it measured

Every entry carries the before-and-after number. Where something is still broken, it says so.

9 August 2026 · Detection

Kills are now read from the picture

The engine now takes game events from the picture as well as the audio. A silent multi-kill that nobody reacted to out loud scores like the fight it was. Where a game is not supported the signal is simply absent and selection behaves exactly as before — nothing gets worse, some recordings get better.

silent multi-kills on an 82-min stream 0 → 3 bursts caught (+4, +3, +5)
In progress

Sharper speaker colours in busy moments

When several people talk at once the engine plays it safe — it colours a line only when it is sure who spoke, so your name never lands on someone else's sentence. Every voice profile added makes it surer, and the hard overlaps keep getting better.

colour accuracy improving with every profile
30 July 2026 · accuracy

Speaker matching got much more accurate

Speaker matching used to fail in both directions at once — missing the right person and occasionally colouring the wrong one. It now weighs a voice against the others actually present in the same recording, which removed both failures together.

separation 0.341 → 0.559 recall 95 % → 100 %
30 July 2026 · safety

Moments, not just words

Masking a slur does not save a clip that is about the joke. Such passages are now removed from selection entirely, before any clip is built — and the gate was hardened after one slipped past an earlier version.

reference stream 5 of 194 segments blocked
29 July 2026 · quality

Highlight detection rebuilt around measurement

Laughter is now heard in the audio itself instead of hoped for in the transcript, and reactions are measured as a build-up rather than line by line — a single exclamation carries no signal, a run of them does.

dull callouts score 0.00 clip length spread 5.6 s → 11.5 s
29 July 2026 · transcription

Invented lines removed

On silent passages the transcriber was inventing lines that nobody said — over two hundred of them reached the screen in a single stream. They are now caught and discarded before anything is written to your captions.

invented lines 202 → 0 high-confidence 81 % → 95 %
28 July 2026 · transcription

Game-aware vocabulary

The transcriber was working from the wrong context, which does not degrade gracefully — it produces confident nonsense. The engine now works out what is actually being recorded before it commits to a word.

detection ~35 s lines below floor 21.1 % → 7.6 %
28 July 2026 · infrastructure

Rendering moved off the operator's machine

All heavy processing now runs on our own servers. Nothing touches the customer's machine, and capacity is rented by the minute when demand needs it.

local CPU load 0 % speaker matching 8 min 35 s → 6 min, remote
28 July 2026 · compatibility

Any source profile, not just one

The engine assumed one recording profile and silently produced nothing on anything else. It now reads the actual properties of every file it is given, so a phone capture and a studio stream both work.

subtitle pixel check 0 % → 100 %
17 July 2026 · first delivery

First full stream through the pipeline

A raw two-and-a-half-hour recording in, finished shorts out, with no manual editing anywhere in between.
